# affirmation-generator

## Overview
This project is a simple web application that generates affirmations and allows users to create and add their own.

## Features
- Generate random daytime affirmations
- Generate random nighttime affirmations
- Add custom affirmations
- Theme selector (light, dark, sunset)
- Responsive design for mobile devices

## Technologies Used
- HTML
- CSS
- JavaScript

## How It Works
The application uses JavaScript arrays to store affirmations. When a user clicks a button, a random affirmation is selected and displayed. Users can also input their own affirmations, which are added to the array and used in future generations.

## Purpose
This project was built to demonstrate foundational web development skills including DOM manipulation, event handling, and working with user input.
